Module: AccountCreationModule
Class: AccountRegistrationHandler -  Manages user account operations, including registration of account data.
Function: registerAccountInDatabase() - Registers a new user account in the database.

Class: AccountInitializationHandler - Manages the initialization of default data for a user in the database.
Function: initializeAccountDataInDatabase() - Initializes default data for a user in the database.


Module: DirectoryManagementModule
Class: SystemHandler - Handles system-level operations, such as creating user directory.
Function: createUserDirectoryStructure() - Creates a directory structure for a user in the system.

Module: NotificationModule
Class: CommunicationHandler -  Facilitates communication by sending notifications to users, including signup success and error notifications
Function: sendSignupSuccessNotification() - Sends a notification to the user upon successful signup.
Function: sendErrorNotification() - Sends a notification to the user in case of an error during the signup process.
